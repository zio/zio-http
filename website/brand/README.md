# ZIO HTTP brand kit (v2, final)

- ZIO HTTP Brand Sheet.html: the full brand sheet. It is one self-contained file that works offline.
- theme-tokens.css: all colours for dark (default) and light mode
- icons/
  - favicon.svg: mint on dark
  - favicon-light.svg: deep mint, for light tabs
  - favicon-adaptive.svg: switches colour with the OS colour scheme
  - favicon-light-bg.svg: deep mint (same as favicon-light.svg, kept for existing references)
  - favicon-mono.svg: currentColor
  - icon-tile.svg: rounded tile
  - icon-maskable-512.svg: PWA / app icon

Accent: #3DDC97 (dark) / #0B7A50 (light)
Fonts: IBM Plex Sans + IBM Plex Mono (brand, hero), Inter (site content)

## In this repository
Reference material only: nothing here is served by the website. The live site's colors are the `--zh-*` tokens in `src/css/custom.css`, and its logo and favicon files in `static/img/` are generated from `assets/zio-http-logo.svg` by `scripts/generate-icons.mjs`.
