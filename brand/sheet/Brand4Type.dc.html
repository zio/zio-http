A tight sans for the name, mono for the code

Inter Tight sets the wordmark, headings and brand material. JetBrains Mono sets code, versions, URLs and labels, with ligatures off. Inter, the face ziohttp.com already uses, keeps the site content below the hero. All three are open source and load from Google Fonts.

4.4
Code
Code uses JetBrains Mono at 13 to 15 px with a 1.7 line height and ligatures off, so ->, <- and @@ look as typed. Five roles, no more: keyword, type, string, comment, plain. The accent is kept for keywords, which keeps it rare enough to stay a signal. The light snippet is the greeting server from the README; the dark one is the endpoint from GreetEndpointExample.scala.
import zio._ import zio.http._ object GreetingServer extends ZIOAppDefault { val routes = Routes( Method.GET / Root -> handler(Response.text("Greetings at your service")), Method.GET / "greet" -> handler { (req: Request) => val name = req.queryOrElse[String]("name", "World") Response.text(s"Hello $name!") } ) def run = Server.serve(routes).provide(Server.default) }
// Endpoint definition val endpoint = Endpoint(GET / "greet" ?? Doc.p("Route for greeting")) .query( HttpCodec.query[String]("name") ?? Doc.p("Name of the person to greet"), ) .out[String] // Endpoint implementation val greetRoute: Route[Any, Nothing] = endpoint.implementHandler( handler((name: String) => s"Hello, $name!") ) // Serving routes def run = Server.serve(Routes(greetRoute)).provide(Server.default)

Every mono setting carries font-variant-ligatures: none. Readers copy what they see; a drawn arrow glyph is not what they type.
Light on #FFFFFF: keyword #0B7A50 (5.37:1), type #4C51BF (6.49:1), string #8A5A00 (5.93:1), comment #6B7385 (4.76:1). Dark on #06080F: keyword #3DDC97 (11.32:1), type #A78BFA (7.35:1), string #4FD1C5 (10.73:1), comment #7E88A0 (5.64:1), plain #C6CCDA (12.44:1).
Light code sits on white: on the #F5F7FA surface the comment colour falls to 4.43:1, under the 4.5:1 floor.
4.5
Rules
Sentence case. Headings and buttons are sentence case: “Get started”, not “Get Started”. Capitals only in mono labels.
Names in mono. Type, method and artifact names in running text are set in JetBrains Mono: Routes, Handler, Server.serve.
Ligatures off. Every mono setting turns ligatures off, so -> stays two characters, the way readers type it.
Inter Tight above, Inter below. Brand material and the hero use Inter Tight; site content below the hero stays in Inter.
Mono is never body copy. Mono is for code, versions, URLs and labels. A paragraph in mono reads as output, not prose.
Write the name as ZIO HTTP. Two words, both in capitals; never “Zio Http” or “ZIO-HTTP”. zio-http is the artifact, zio.http the package.
