7.3
Rules
Arrows frame the page. The request arrow opens the hero in the accent, the response arrow closes it in the text colour. Both are 6 px bars across the full content width, labelled in mono caps.
One accent per screen. Mint goes to the request arrow, “Powered by ZIO”, the code keywords and the one filled button. The second action is an outline.
Live numbers only. Stars and the latest version come from the GitHub API when the page loads; the fallbacks and the contributor count live in RepoStats/data.js. Never type them in by hand.
No version in the banner. The README pins 3.3.2 while the site reports 3.11.x, so the banner shows the coordinates and the site without a number, and the install section below it carries the version.
