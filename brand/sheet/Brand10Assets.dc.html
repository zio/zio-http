Update
These are the files in website/brand/ in the zio-http repository. The six logo files, the two cards and the overview picture in logo/ still set the mark beside “ZIO HTTP” in IBM Plex Sans as live text: re-export them with the wordmark from section 1, converted to outlines, so the logo never depends on a font being installed. The kit is reference material. The live site reads the same --zh-* tokens from website/src/css/custom.css, and its logo and favicons in website/static/img/ are generated from website/assets/zio-http-logo.svg by website/scripts/generate-icons.mjs.

Every value is from theme-tokens.css; the two font tokens are a proposal, the file has none yet. Use the role names, not the hex values, so a page switches theme in one place. Names start with --zh- so they never collide with another ZIO library’s tokens on a shared page. The light comment colour, #6B7385, is 4.4:1 on --zh-surface and 4.8:1 on white: darken it to #646C7E (4.9:1), as the Colour board proposes, so comments pass AA and stay a shade apart from secondary text.
