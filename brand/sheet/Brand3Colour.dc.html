Brand sheet · 03 · Colour

Mint on navy, deep mint on white

One accent in two tones: mint on dark grounds, deep mint on light ones. Dark mode is the default, as on ziohttp.com. Everything else is navy, white and three greys, and every value maps to a --zh-* token in theme-tokens.css. The palette names on this board (void, slate, mist) are a proposal; the tokens are the source of truth.

3.2
Light and dark mode
Dark mode is the default, as on ziohttp.com; light mode is set with [data-theme="light"]. The accent swaps tone between modes: mint on dark, deep mint on light. Buttons swap their label too: navy on mint (10.71:1), white on deep mint (5.37:1).

3.3
Contrast pairs
Ratios are computed from the hex values with the WCAG 2.x formula. Text needs 4.5:1; icons and type of 24 px and up need 3:1. The rule that follows: each mode has its own accent tone, and the two never cross. Mint on white fails even the 3:1 for graphics, and deep mint on navy fails for text.

3.4
Code colours
Five roles, no more. The accent is kept for keywords, which keeps it rare enough to stay a signal. Code sets in JetBrains Mono with ligatures off, so -> stays two characters. The snippet is the greeting server from the README.
DARK · ON SURFACE #0B1020
import zio._ import zio.http._ // two routes: / and /greet?name=... object GreetingServer extends ZIOAppDefault { val routes = Routes( Method.GET / Root -> handler(Response.text("Greetings at your service")), Method.GET / "greet" -> handler { (req: Request) => val name = req.queryOrElse[String]("name", "World") Response.text(s"Hello $name!") } ) def run = Server.serve(routes).provide(Server.default) }

Proportion
Mostly ground and text; mint is a trace. The rules come from the site design: one filled accent button per screen, the accent kept for keywords in code, and in the hero only “Powered by ZIO” takes it. If mint fills a section it has stopped marking anything. Bar widths are indicative, not measured.

3.6
In the ZIO family
Every ZIO library owns one hue on the same navy-and-white ground, and each sets its Z in that hue. Mint is the only green in the family: its hue (154°) is 75° from the nearest sibling accent, ZIO Blocks (229°). Like Logging's amber, it has a deeper tone for light grounds.
