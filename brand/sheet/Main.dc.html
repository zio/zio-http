ZIO HTTP brand

The mark is a round trip: a request goes out along the top arrow and a response comes back along the bottom one. Read as one shape, the two arrows are the Z of ZIO, so the wordmark sets them in front of “IO HTTP” in Inter Tight Bold. Mint is the one accent. Everything else in this sheet grows from that one construction.

0.1
The idea in three steps
STEP 1
A request goes out
One arrow pointing right: the client sends a request. A bar with a 45° head, a 3-unit stroke and round ends, on a 32-unit grid.
STEP 2
A response comes back
A second arrow, 10 units lower, points back: the server answers. ZIO HTTP models HTTP as a function from a request to a response, on the server and in the client.
STEP 3
The arrows become the Z
Top bar, diagonal, bottom bar: the pair traces a Z (red dashes). Set in front of “IO HTTP” it is the first letter of ZIO, and it takes the mint accent.

Dark mode is the default: page #06080F, cards and code on navy #0B1020. Mint is the one accent: the mark, links and one highlight per layout, 11.32:1 on the dark page. On white mint drops to 1.77:1, so light grounds use deep mint #0B7A50 (5.37:1) for the mark, links and text. Every value is a --zh-* token.
